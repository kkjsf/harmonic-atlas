Chord ModeHow many chord tones to stack per degree. Triads = 3 notes (R-3-5). 7ths adds the 7th. 9ths/11ths/13ths extend further. Chromatic modes add borrowed non-diatonic chords.
Diatonic?
Diatonic ModesChords built only from notes within the current scale. Each degree of the scale becomes a chord root; thirds are stacked using only scale tones. These are the native chords of the key.
Chromatic?
Chromatic ModesNon-diatonic chords that use notes outside the scale. They create tension, colour, and harmonic movement. Secondary dominants, leading-tone chords, subdominant substitutes, and chromatic mediants each have distinct flavours.

Negative HarmonyPopularised by Jacob Collier (Ernst Levy). Mirror every note of a chord around the axis between the tonic and its perfect fifth. Major chords become minor, dominant 7ths become half-diminished - everything flips. The axis is shown as a red line on the Circle of Fifths.

Cadence Suggester ?
CadencesA cadence is a chord sequence that creates a sense of resolution or pause. Perfect = V→I (strongest closure). Plagal = IV→I (church "amen"). Deceptive = V→vi (surprise). Half = ends on V (unresolved). Click any chord chip to add it to the active composition.

Pivot Chord Finder ?
Pivot ChordsFind chords that exist in both the current scale and a target scale/key. These shared chords are perfect pivot points for smooth modulation — play the chord in context of the first key, then reinterpret it as a degree in the new key.

Chord Theory Engine
Scale data37 scales encoded as interval arrays. Families: Major modes (7), Harmonic Minor (7), Melodic Minor (7), Exotic (7 inc. Hirajoshi, Whole Tone, Arabian), Bebop (4: Phrygian Bebop, Bebop Dominant, Bebop Major, Bebop Dorian), Pentatonic (3: Major, Minor, Blues), Symmetric (2: Half-Whole, Whole-Half dim). 5–8 note scales supported.
Chord stackingchordIntervals() - iterative stacking of thirds by scale degree; handles wrap-around octave context
Chord namingclassifyChord() - recursive classifier; N=3 triads → N=7 full 13th chords. Lead-sheet standard: maj7/m7/7/ø7/dim7; cumulative extensions; alterations suffix. Assumes a stack of thirds, which chordIntervals() only produces on seven-note scales, so anything it cannot name falls through to classifyNonTertian(): pentatonic, hexatonic and octatonic scales stack scale STEPS and yield sus, quartal and added-tone sonorities, named from their interval content (core third / fifth / seventh, then added tones with explicit no5 / no3 markers). Compound intervals stay compound - 15 semitones is a ♯9, not a ♭3.
Step formulascaleFormula() derives the H / W / A2 / m3 / M3 step pattern from the interval array at render time, so the displayed formula can never drift from the actual scale. A 3-semitone step reads A2 in a heptatonic scale (adjacent letter names) and m3 when the scale has fewer degrees and skips a letter.
Keyboard accessa11yTagClickables() gives every clickable div / span / SVG path a tabindex, a role and a label after each render; a MutationObserver re-tags whatever gets rebuilt, and one delegated handler turns Enter / Space into a click. Circle-of-Fifths slices are all labelled for assistive tech but only the diatonic ones join the tab order, and the hover readout also fires on focus.
Enharmonic spellingspellScale() - sequential letter assignment for heptatonic; PREFER_FLAT_PC set for pentatonic
Roman numeralsCompared against Major reference intervals; handles pentatonic degree naming separately
Chromatic chordsSecondary dominants, secondary diminished, subdominant substitutes, chromatic mediants - all computed at render time from scale degree analysis

Arpeggio Engine
SystemCAGED-based: 5 positions anchored by root on each string (E, A, D, G, B). Each shape labelled E form, A form, D form, G form, C form.
Fret windowCompact 5-fret span: anchorFret ± 2. All chord tones on all 6 strings within the window are candidates.
Note selectionEvery chord tone in the position, taken in strictly ascending pitch (so a correct R–3–5–7 cycle, but starting on whichever chord tone is lowest in the window rather than always the root). Max 2 notes per string, minimum 4 notes per shape. The root on the anchor string is ringed in gold, since that is the dot the form is named after.
Scope7th chords only (4 pitch classes). Disabled for triads. Works with diatonic, secondary dominant, and secondary diminished chord modes.
SVG diagramsHorizontal fretboard: strings horizontal (E bottom → e top), frets as vertical lines. Gold dots = root, purple = other chord tones, note names inside dots. Click opens near-fullscreen modal (98vw × 96vh); mouse-wheel or pinch zooms up to 6×; overflow scrolls to pan.

Banjo Engine
TuningOpen G, gDGBD. Melody strings 4th-1st = D3-G3-B3-D4 (MIDI 50-55-59-62); 5th string = a fixed g drone (G4, MIDI 67) whose nut sits at fret 5, so its first fretted note is fret 6.
Drone handlingPer grip the 5th string is shown fretted when the shape reaches past fret 5 and lands on a chord tone, open when g itself belongs to the chord, and crossed out otherwise - a clash you keep out of the roll rather than a note you play.
Scale viewMelody strings only. The 5th string has its own nut, so it shares no fret grid with the other four and cannot be drawn on the same map.
Closed-Grip Engine — mandolin Chop · banjo Moveable
Why closedA chop speaks because the whole grip lifts off at once. One open string keeps ringing and the percussive snap is gone, so the search only ever returns voicings with every string fretted - which is also what makes the shapes moveable to any root.
SearchExhaustive over which chord tone lands on which string, then over every per-string octave shift. Shapes are cached per interval set, so exotic scales get real grips instead of a fallback table.
Playability filter≤4 fingers, counting one finger per maximal run of adjacent strings on the same fret (non-adjacent strings sharing a fret each cost a finger; a damped course breaks the run and costs none). On banjo the fretted strings sit at most 3 frets apart (the hand covers four frets; open strings do not count, and an open-position grip stays at or below fret 5). A four-fret reach that breaks one-finger-per-fret (two separate fingers on one fret, or a barre by any finger but the index) ranks after a compact grip nearby, and the 5th string is fretted only when a finger is free. Span ≤5 on mandolin: the traditional chops stretch that far, and a four-fret cap silently deletes them.
Five-fret stretchAllowed one way round only: the highest fret on the bass side and the lowest on the treble side, which is how the hand angles (pinky reaching up the neck, index sitting back). The mirror image is not a grip. Also needs to sit at the 2nd fret or above, where the frets have closed up.
Damped courseMandolin only, and only the top course: a fretting-hand mute you simply do not strike. It is how the small chop gets its reach down. Damping the G would throw away the bass weight the chop lives on, so it is never offered.
Required tonesRoot, third (or the sus tone) and any altered fifth / sixth / seventh must sound. The perfect fifth may be dropped — the documented D chop 7-4-5-2 is D F♯ D F♯ and has none — but it costs points, so ordinary voicings still prefer the whole chord.
RankingTight span, then doubling (root and fifth free, doubled third penalised, doubled seventh heavily), then bass-side weight: fretting the G and D courses high is what gives the chop its bark and the pick something to aim at. The grip shown first also pays for height, and a named chop hands its bonus back above the 5th fret — which is why G chops 7-5-2-3 but C chops 5-2-3-3 rather than 12-10-7-8.
Named chopsBig Chop = 5-R-3-R, root on the D course, five frets wide (G: 7-5-2-3 = D G B G); its sibling voicing for D is 7-4-5-2. Small Chop = the same idea with the pinky brought home and the top course damped (G: 4-5-2-✕, C: 5-2-3-✕). Both are guaranteed a pill whenever they are in reach, even when the score would crowd them out.
AlternatesUp to four grips per chord, at most two per root string so they are different ideas rather than four fingerings of one. Pills are labelled by the string carrying the root - with its number on banjo, which has two D strings.
Other named shapesMandolin E shape (the open-E grip, 1-2-2-0 moved up), G shape (open G, 0-0-2-3 — and open A, 2-2-4-5, is the same shape), D shape (open D, 2-4-5-5); banjo Barre, F shape, D shape. Descriptive only, each verified against the open chord it derives from.

01
Overview

The Harmonic Atlas is a complete music theory reference for any key and scale. It harmonises a chosen scale into full chord stacks - from basic triads through 13th chords - and offers guitar, mandolin and banjo diagrams, a circle of fifths, scale relationships, a cadence suggester, and a composition tool that plays your progressions back.

The tool covers 37 scales across seven families: Major Modes, Harmonic Minor, Melodic Minor, Bebop (Dominant, Major, Dorian, Phrygian), Pentatonic (Major, Minor, Blues), Symmetric (Half-Whole, Whole-Half) and Exotic (Neapolitan Minor, Hungarian Minor, Byzantine, Hirajoshi, Whole Tone, Arabian). Every scale is presented in all 12 keys. Notes are spelled the way a musician reads them: one letter per degree (B♭ not A♯ in F major), each note named after the degree it stands for in pentatonic and bebop scales (E major pentatonic is E F♯ G♯ B C♯), and the simpler of two enharmonic tonics (C♯ minor, not D♭ minor). Where a diatonic Maj7 chord has a ♯11 available in the scale, a Δ7♯11 (Lydian chord) is shown as an alternative voicing.

💡 The left column holds reference tools (circle of fifths, scale relationships, cadences, substitutions, pivot chords, ear training). The right column always shows the chord view.
02
Choosing Key & Scale

Set the Root Key with the ▼ ▲ buttons (one semitone at a time) and pick the Scale / Mode from the list, grouped by family; type in the filter box to narrow it. Every panel updates instantly.

Root Key Sets the tonic of the scale. All note names and chord roots adjust automatically with correct spelling. Scale / Mode Selects from 37 scales across 7 families. Each scale is described in the Scale Hero banner with its characteristic colours and degrees.
🎸 Guitar players: the Scale Hero note pills show the notes in order. Click any pill to jump to that degree's chord cards in the right panel.
03
Chord Modes

Two groups of chord mode buttons sit below the selectors. Diatonic modes (gold border) build chords entirely from the scale notes. Chromatic modes (purple border) introduce non-diatonic chords for harmonic colour.

Diatonic modes:

Triads Three-note chords: root, third, fifth. The bedrock of harmony - major, minor, diminished, augmented. 7ths Four-note chords adding the seventh. Adds colour and tension: maj7, m7, dom7, ø7, dim7. 9ths Five-note chords extending to the ninth (compound 2nd). Jazz-standard density - m9, maj9, 9, ø9. 11ths Six-note chords. The eleventh adds suspension-like friction, especially ♯11 in Lydian contexts. 13ths Full seven-note chord stacks. Every scale degree voiced simultaneously - the richest harmonic texture. Others Sus2, Sus4, add9, add11, M6, m6, 6/9, m6/9, augmented, diminished, power chord (5), 7sus4, Maj7sus4, 7sus2 — all built from scale tones where available.

Chromatic modes:

Secondary Dom. V7 chords targeting each diatonic degree (V/ii, V/IV, etc.). Each card shows common alterations — 7♭9, 7♯9, 7♯11, 7♭13, 7♭5, 7♯5 — a ♭II tritone substitution, and a 🎸 voicings button opening guitar chord diagrams for all altered dominant shapes. Secondary Dim. vii° chords a semitone below each diatonic root. Tighter chromatic pull than secondary dominants. Secondary Sub. IV chords a perfect fourth above each degree - the subdominant of each degree, adding modal colour. Chr. Mediants Chords a major or minor third away from the tonic sharing one common tone. Romantic, filmic, surprising.
🎹 Chord symbols follow standard jazz notation. The interval line below each chord name shows exact semitone distances from the root, so you can verify the voicing on any instrument.
04
Scale Hero Banner

The full-width banner directly below the chord mode buttons shows the current scale at a glance: its family, the degree identity line (e.g. 1 2 ♭3 4 5 ♭6 ♭7), and large note pills in scale order. A Steps toggle reveals interval arcs between each note pill showing the semitone distance (½ = half step, 1 = whole step, 1½ = minor 3rd, 2 = major 3rd).

Below the note pills, a live treble-clef staff shows the ascending scale in standard notation — noteheads, stems, accidentals, and ledger lines rendered in real time. A small ▶ play button sits to the left of the staff; clicking it plays the scale up one octave, clicking again stops it.

The right panel shows a concise description of the scale's characteristic colour and harmonic applications.

👆 Clicking any note pill scrolls the chord panel to that scale degree's chord cards. The ♩ icon on each chord card opens an inline stacked-chord staff notation for that chord. The search history strip above the banner shows your recent key+scale navigations.
05
Circle of Fifths

The Circle of Fifths arranges all 12 keys clockwise by ascending perfect fifths. The outer ring shows major keys, the middle ring their relative minors, the inner ring diminished chords.

Segments highlighted in gold are major chords of your scale; purple are minor chords; orange are diminished chords. Keys adjacent on the circle share the most common notes — useful for modulation planning.

🖱️ Hover works in both directions: hover any CoF segment to highlight the matching chord card (and see a tooltip with name + quality) — including non-diatonic positions. Conversely, hover any chord card to highlight its slice on the circle.
06
Chord Views

Four tabs above the right panel switch the display mode for all chords:

Chord List Default view. Each degree shows one card with the chord symbol, quality, note names, and interval stack (e.g. 1 · ♭3 · 5 · ♭7). Guitar Seven sub-tabs for guitar-specific views:
Basic A chord diagram for each chord. Triads and 7ths come in open position first, the way a guitarist learns them (C = x32010, G = 320003, E7 = 020100); a triad with no open shape takes the lowest barre shape (C♯m = x46654). The root is always the bass note. Shapes requiring a barre are shown with a purple bar across the relevant strings and a small B marker. Gold dot = root, purple = other chord tones. Arpeggios Horizontal fretboard diagrams showing ascending arpeggio shapes for 7th chords across the CAGED system (E, A, D, G, C forms). Each shape covers a compact window; the root the form is named after is circled in gold. Only available in 7th chord modes. Scale The whole scale on a 15-fret fretboard, then the five CAGED positions. A chord-tone overlay highlights the tones of any degree's chord; Notes / Degrees switches the labels. Shell Guide-tone voicings (root, 3rd, 7th) on adjacent and skipped string sets, the comping shapes of jazz guitar. Drop 2 Jazz voicing: the 2nd-highest note of a close-position chord dropped one octave. Shows all 4 inversions × 3 string sets (E-A-D-G, A-D-G-B, D-G-B-e). No open strings. Inversion label shown as slash notation, e.g. Gmaj7/B for 1st inversion. Drop 3 Jazz voicing: the 3rd-highest note dropped one octave. Wider, more open voicings on non-adjacent string sets. Same 4 inversions × 3 sets. Used in big-band arranging. Click any diagram to zoom. Alt. Dom Altered dominant voicings for all dominant chords in the current key (V7, secondary dominants). Covers 12 chord types: 7♭9, 7♯9, 7sus4♭9, 13♭9, 13♯9, 7♯11, 7♭13, 7♭9♭13, 7♭5♭9, 7♭5♯9, 7♯5♭9, 7♯5♯9. Each shows up to 3 moveable shapes (E-str., A-str., D-str.) with the root on a different string. Shapes are compact (span ≤ 4 frets). A tritone-substitution note is shown for each root. Only appears when the scale contains dominant chords.
Mandolin Three sub-tabs for mandolin (G-D-A-E tuning):
Chords Standard mandolin chord diagrams, may include open strings. Click to zoom. Scale Full fretboard scale map for mandolin. Swipe horizontally on mobile. Chop Chop chords — closed shapes for triads and 7ths. Strike on beats 2 & 4 and kill the ring by releasing finger pressure: the snap comes from the release, which is why an open string ruins it. Two things make a grip chop — no open strings, and weight on the bass side (the G and D courses fretted high, which is where the bark comes from and what the pick aims at). The big chop is the four-finger stretch, five frets wide, root on the D course: G is 7-5-2-3. The small chop brings the pinky home and damps the top course (G: 4-5-2-✕) for faster changes and smaller hands. Dots are labelled by interval (R, 3, 5, ♭7), the row under the string names is a suggested fingering, and ✕ marks a damped course. Pills switch between grips: the letter is the course carrying the root, and a trailing ✕ means a course is damped.
Banjo Three sub-tabs for 5-string banjo in open G (g-D-G-B-D):
Chords Chord shapes with open strings allowed, so first-position G, C and D land where you expect. The 5th string is drawn short because its nut is at fret 5 — open when g belongs to the chord, fretted when the grip reaches past fret 5, crossed out when it clashes and should stay out of the roll. Scale Full fretboard map of the four melody strings. The 5th string is left off: it has its own nut, so it shares no fret grid with the others. Moveable Closed shapes — the three grips of bluegrass banjo (barre, F shape, D shape) plus whatever else a chord needs. No open strings, so they move to any root: this is how you get out of open G and up the neck.
🎸 Drop 2 and Drop 3 voicings follow the jazzguitar.be standard. Arpeggio shapes use the CAGED system to map 5 positions across the fretboard for each 7th chord.

Scale Relationships

This collapsible panel (left column) shows three groups of related scales. Each chip now shows a brief explanation of why the two scales are related. Click any chip to instantly navigate to that scale — handy for modal interchange and modulation planning.

Relative Scales that share every note but start on a different root. The chip shows which mode of the current scale it corresponds to — e.g. "3rd mode of Major (Ionian) — same 7 notes." Parallel Scales with the same root but different note sets. The chip shows how many notes differ and which ones — e.g. "Same root, 1 note different (Bb altered)". Closely Related Scales differing by only one note with a root a semitone or two away — the subtlest modulation targets. Shows shared note count and root distance.

Negative Harmony

Popularised by Jacob Collier (from Ernst Levy's theory). Every note of a chord is mirrored around an axis between the tonic and its perfect fifth. The result inverts the harmonic polarity: major chords become minor, dominant 7ths become half-diminished.

C → Cm (neg) G7 → Dø7 (neg) Am → E♭ (neg)

The axis is shown as a red dashed line on the Circle of Fifths, with arcs connecting mirrored pitch pairs. Only available in Ionian (Major) mode. When active, the Circle of Fifths shows only the mirror arcs (diatonic highlights are suppressed).

Original card Left card — the diatonic chord as usual. Negative card Right card — the mirrored chord with its own guitar voicing diagram. Hover the pair to see a tooltip showing how each note transforms (e.g. C → G, E → E♭, G → C, B → A♭ for Cmaj7). Persistence The toggle state is saved. If you switch to another scale and return to Ionian, Negative Harmony re-activates automatically.
🪞 Use negative harmony to find unexpected chord substitutions — the negative of ii–V–I in C (Dm7–G7–CΔ7) is Gm7–Dø7–A♭Δ7: the same pull toward C, in a darker colour.

Pro Tips
🔁Modal interchange: stay in C Major but click a Dorian or Mixolydian scale chip from Scale Relationships - add their chords to your composition with the + button to borrow modal colour.
🎯Finding pivot chords: use Compare mode to put your current key and target key side by side - the SHARED chords are your pivot candidates for a smooth modulation.
🎷Jazz voicing workflow: switch to 7ths mode → use the Drop 2 view to find voicings → add the chords to a composition → play it back with the Guitar sound.
🌐Circle of Fifths navigation: hover adjacent segments to hear (visually) how close two chords are - gold + purple neighbours make the smoothest voice-leading moves.
⚡Quick progressions: click a Cadence Suggester row chord by chord to assemble a full cadence in the active composition, then hit Play to audition it.
